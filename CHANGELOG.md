# Changelog

All notable changes to Business Links are documented here.

## 1.7.0

### Added
- Configurable tile background color
- Configurable tile border color
- Configurable hover/accent border color
- Configurable icon background color
- Configurable tile corner radius
- Tile density presets: Compact, Comfortable, Spacious
- Option to show or hide application descriptions
- Live tile preview in Administration settings
- Default tile styling switch for reverting to the standard Nextcloud-aware design

### Changed
- Appearance settings are now organized to include panel and tile customization
- Tile styling is applied through reusable CSS variables

## 1.6.1

### Improved
- Horizontal and vertical panel resizing
- Administrator-configurable default panel width and height
- Reset-to-default size behavior

## 1.6.0

### Added
- Resizable launcher panel
- Per-user panel size persistence
- Maximize and reset controls

## 1.5.0

### Added
- Configurable panel color
- Default Nextcloud color reset switch

## 1.4.0

### Added
- Custom display name and subtitle branding

## 1.3.0

### Added
- Application descriptions

## 1.2.0

### Added

## 1.1.0

### Added
- Application search

## 1.0.0

### Added
